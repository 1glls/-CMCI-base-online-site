🛡️  SÉCURITÉ (nov. 2026)
La route /api/auth/register n'est plus ouverte à tous :
  • base vide (tout premier lancement) → création libre du 1er admin ;
  • sinon → réservée à un administrateur déjà connecté.
Sans cette protection, n'importe qui pouvait se créer un compte
admin sur le site en ligne.

═══════════════════════════════════════════════════════════════

✅ MÉTHODE RECOMMANDÉE (local ou VPS) : le script du serveur

    cd src/backend
    node scripts/creer-admin.js admin@cmci.be "Admin CMCI"

  → le mot de passe est demandé au clavier (masqué, 8 caractères min.)
  → si l'email existe déjà, SEUL son mot de passe est remplacé
    (pratique en cas de mot de passe oublié)

Le script écrit directement dans la base : il ne fonctionne que sur
la machine qui héberge la base de données (votre PC ou le VPS).

─────────────────────────────────────────────────────────────

🆕 PREMIER LANCEMENT (base vide)

    1. Démarrer le backend :  ./demarrer-backend.sh
    2. Dans un 2e terminal :  cd otherthings/scripts && ./create-admin.sh
       (ou le script ci-dessus, qui marche aussi)

🔑 SE CONNECTER

    Local      : http://localhost:3005/admin   (port de dev du projet)
    Production : https://www.cmcibelgique.org/admin
